# E系列標準値一覧

## 目的・範囲

`/tools/e-series/` でIEC 60063:2015のE3 / E6 / E12 / E24 / E48 / E96 / E192を参照する。ホームの技術資料と共通navigationからリンクする。

## 数列・表示

- 表1のE24と表2のE192を明示的な整数配列として保持する。単なる等比数列の丸めで代用しない。
- E24を2項ごとに間引きE12、E6、E3を得る。E192を同様に間引きE96、E48を得る。
- E3〜E24は10〜91の2桁、E48〜E192は100〜988の3桁の整数。末端の次decade開始値は重複表示しない。
- 表は1 decade分。値に10の整数乗を掛けて使用できること、2桁と3桁の表示scaleが異なることを表付近で説明する。
- E3 ⊂ E6 ⊂ E12 ⊂ E24、およびE48 ⊂ E96 ⊂ E192。E24はE48以降の部分集合ではないことを明示する。

## 主表

- Desktopの横方向はE3 | E6 | E12 | E24 | E48 | E96。
- E24の24値を各行の基準とし、E3 / E6 / E12の同値を同じ行へ配置する。
- E48 / E96は表示scaleを揃えた上で比率の対数距離が最小のE24の行に配置する。共通値は必ず同じ行。近似グループであり、公差範囲や厳密な包含を意味しない。
- 行内は左から右、次に上から下へ昇順。E48は最大3列、E96は最大6列の固定枠。値がない枠は空欄。系列ヘッダはcolspanで各枠をまとめる。
- E24と桁を揃えると一致するE48 / E96の値は太字。淡い行背景、系列境界、4行ごとの罫線で位置を追えるようにする。
- 強い系列色は使わず既存のlight / darkのtokenで構成する。

## E192

主表の横幅を増やさないため、その下に独立した8列×24行の専用表を表示。各列を上から下へ読み、右列へ進む。列ヘッダには範囲と下向き矢印。E96にも属する値を太字とし、説明を付ける。192値すべて常時展開する。

## 公差

各系列ヘッダ付近に「例 ±40% / ±20% / ±10% / ±5% / ±2% / ±1%」、E192に「例 ±0.5%」。系列だけから部品公差は決まらないと説明する。

IEC 60063:2015 表3は対称公差と系列の推奨対応であり、E3は±20%より広い公差、E192は±1%より狭い公差。±40%や±0.5%への固定を規格要求として説明しない。

## コピー

各系列ヘッダ付近のLucide Copy icon buttonで、その系列だけをカンマ＋スペース区切りでコピーする。1以上10未満、E3〜E24は小数1桁、E48〜E192は小数2桁（末尾0を保持）。見出し・公差・単位・改行・末尾カンマは含めない。

accessible nameは`E24をカンマ区切りでコピー`等。成功は2秒間Check表示とlive status、失敗は権限確認・再試行を促す表示。実行中はbutton無効。JavaScript無効でも表はSSRにより参照可能。

## Mobile・操作性

表のみ横・縦スクロール可能。読みやすい文字サイズと固定列幅を保ち、セルを折り返さない。左右矢印と説明を表示。表のスクロール領域はfocus可能な名前付きregionとし、keyboardで操作可能。系列ヘッダは表内scrollに対してsticky。ページ全体の横overflowは禁止。

## 検証・Visual

数列の件数・順序・包含・既知値・コピー精度・全値の配置をunitで検証。browserで全系列のclipboard、失敗・再試行、sticky header、scroll、320 / 412 / 768 / 1440pxでのoverflowとaxeを確認。

Desktop / Pixel 7、light / darkのfull page、主表全体、Mobile左右scroll・末尾scroll、E192、copy成功時の確認素材と結果を1つのZIPへまとめる。実機ではなくLinux上のエミュレーションであることを記載。baselineは人間承認前に追加・更新しない。既存architectureで実装できるため新規ADRは不要。
